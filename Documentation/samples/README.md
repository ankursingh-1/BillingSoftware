# Sample files

`product-import-test.xlsx` is regenerated by the product-import unit tests.

- Fill-in template: Products → Import Excel → Download template (includes Instructions, Lookups and a Sample sheet that is **not** imported).
- This test workbook has rows on the **Products** sheet: two valid (`SAMPLE-USB-01`, `SAMPLE-HDMI-01`), a missing name, a negative price, an identical duplicate of `SAMPLE-USB-01`, and `EXISTING-1` which is unchanged when that SKU already exists with the same details.

Do not import it into the live shop database. Use a Verify/copy database.
